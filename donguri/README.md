# どんぐりFX 変更版

## 変更
- 細かな不規則な値動き、時間ごとの荒れ具合、可変スプレッド。
- 30分の枠ごとに架空ニュース。発表後に価格へ反映し、影響は徐々に減衰。
- ニュース用の追加ライブラリ、APIキー、DBテーブル、常駐ジョブは不要です。

## 導入
このフォルダの price.js、server.js、public/index.html をGitHubの同名ファイルと置き換え、既存のRenderの手順で再デプロイしてください。DATABASE_URL、SECRET、PRICE_SEEDは既存の値を維持してください。RenderやNeonの設定変更は不要です。

価格モデルの変更により、既存ポジションの評価額・過去にさかのぼるロスカット判定が変化します。利用者に告知し、可能なら全員が決済したタイミングで切り替えてください。元版はDownloads内に残しています。

## 検証範囲


価格は実相場データではなく、時刻とシードから生成するゲーム用シミュレーションです。ニュース一覧に未来の発表は出しませんが、現在の設計はシードを知る人による将来価格計算を暗号学的に防ぐものではありません。

## ローカルのテストプレイ
`npm install` 後、`npm run local`（または `node local.js`）で起動し、http://127.0.0.1:3000 を開きます。名前 `test`、パスワード `5447` でログインできます。ローカルモードはDATABASE_URLを無視し、メモリだけに保存します。再起動するとテスト資産・取引履歴はリセットされます。通常の `npm start` ではテストアカウントは作成されません。
価格は閉じている間も時刻に沿って進みます。不在中の判定は次のアクセス時に遡って行います（最大14日、時間刻みの近似判定）。

## 全プレイヤー共通の相場
価格と架空ニュースはサーバーの時刻と共通のPRICE_SEEDから決まります。ユーザー名・残高・取引履歴は価格計算に使いません。同一時刻・同一シードなら、別プロセスでも同じ結果です。PRICE_SEEDは再デプロイや複数サーバーでも同じ固定値を維持してください。画面は1.5秒間隔で価格を取得するため、通信・更新タイミングによる一時的な表示差はあります。実際の経済ニュースの表示・外部取得APIは削除しました。
## 予約注文・利確・損切り
レバレッジ取引の「注文方法」で成行／指値／逆指値を選べます。ロング（買い）とショート（売り）の両方に対応し、注文と同時に利確・損切り価格を設定できます。保有後はポジション欄の「利確・損切り」から変更でき、空欄を保存すると解除します。予約注文タブから取消できます。現物取引は従来どおり成行です。

予約注文は14日間有効、最大20件、ポジションは最大10件です。証拠金は予約時には確保せず、成立時に引き落とします。資金不足・保有上限の場合は失効して通知します。複数の予約は登録順で処理します。

買いエントリーはAsk、売りエントリーはBid、ロング決済はBid、ショート決済はAskで判定します。成立価格は条件を満たした判定時点の売買価格です。指値は指定価格か有利な価格、逆指値は急変時に不利な価格で成立する場合があります。利確または損切りでポジションが消えると、もう一方も消えます。同じ判定時刻でロスカットにも該当するとロスカットを優先します。新規成立したポジションの出口は次の判定時刻から有効です。

判定はUTCの固定2秒刻みで、アクセス時に最大14日分を再生します。アクセスごとの可変間隔だった旧判定から変更し、同じ注文・同じ相場の判定がアクセス頻度に依存しないようにしました。2秒未満の一瞬の価格到達は拾えないため、取引所の全ティック再現ではありません。14日を超えてアクセスがない場合、古い期間の成立は復元しません。

追加DBテーブル・外部APIは不要です。GitHubには新しい orders.js も含めて更新してください。

検証：4種類の予約（買い／売り×指値／逆指値）、ロング・ショート双方の利確と損切り、Bid/Askの判定、急変時の成立価格、証拠金不足、有効期限、二重決済防止、不在と定期アクセスの再生結果、取消、設定解除、不正入力を確認しました。ローカルの実画面でも予約登録・取消・保有ポジションの設定変更を確認しました。
